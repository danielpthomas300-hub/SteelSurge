How to play

  • In FTC, the first 30 seconds of a match are autonomous: the robot runs code with no driver.
  • Build a program from command blocks, then press Run to watch your robot follow it exactly.
  • Drive onto a yellow sample and Grab it. Carry it to the green basket and Score. The robot holds one sample at a time.
  • Score every sample to clear the level. Use as few blocks as par for 3 stars.
  • Later levels add a Repeat block: it runs the block after it 2 or 3 times.
