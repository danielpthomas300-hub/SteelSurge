Code Lab

Practice FTC programming

Learn the Java that runs FTC robots, right in your browser: find bugs in real robot code, write methods that get checked instantly, then program a robot and drive it. Plus short CAD and outreach lessons for the whole team. No setup and no account needed.

The Code Lab runs a simplified Java in your browser, so it doesn't need Android Studio. It follows the FTC SDK's names and rules, but real robots use the full SDK: see FTC Docs and Game Manual 0 when you're ready. Your progress is saved in this browser.
